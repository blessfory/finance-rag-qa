## 四、本次修复

1. **FAQ 路由前置**：原先只有意图为 `faq` 才查 FAQ，导致「银行承兑汇票是什么」这类问法被判为
   `knowledge`，绕过了 FAQ 库。现改为 `intent in ('faq', 'knowledge')` 均先尝试 FAQ，未命中再
   降级到向量检索（`rag/rag_service.py`）。
2. **阈值下调 0.85 → 0.70**：实测 0.85 会漏掉「什么是 LPR」这类改写问题；0.70 可命中 FAQ，
   且不会误命中「兴业银行 2024 年营业收入」这类知识类问题（`rag/rag_service.py`）。

修复效果：FAQ 类问题从 11.9s（走 RAG）降到 0.4s（命中缓存）。

## 五、已知限制

- FAQ 库仅 17 条，覆盖面窄；未命中时依赖向量检索。
- 知识问答首问约 23s，主要耗时在 BGE-M3 / Reranker 冷启动与 LLM 生成长答案。
- 财报分析的「事实抽取 / 指标计算 / 跨年对比」已移除，仅保留可验证的检索链路。
- 未实现流式输出；前端为 Streamlit / FastAPI，无鉴权。
- `tests/test_minimal.py` 为静态检查脚本，非真正单元测试。
