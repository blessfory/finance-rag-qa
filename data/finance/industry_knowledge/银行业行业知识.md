# 一、银行业监管法规

## 1. 商业银行法（核心条款）

- **资本充足率**：商业银行资本充足率不得低于8%，核心一级资本充足率不得低于5%
- **存款准备金**：商业银行须按央行规定缴存存款准备金
- **贷款集中度**：对同一借款人贷款余额不得超过资本净额的10%，对最大十家客户贷款总额不得超过资本净额50%
- **关系人贷款**：不得向关系人发放信用贷款，向关系人发放担保贷款条件不得优于其他借款人

## 2. 流动资金贷款管理办法

- 流动资金贷款是指银行向企业法人或国家规定可以作为借款人的其他组织发放的用于日常生产经营周转的本外币贷款
- 贷款期限原则上不超过1年，最长不超过3年
- 银行应合理测算借款人营运资金需求，审慎确定贷款额度
- 实行"实贷实付"原则，贷款资金应通过受托支付或自主支付方式支付给约定交易对手

## 3. 个人贷款管理暂行办法

- 个人贷款按用途分为个人消费贷款和个人经营贷款
- 贷款人应建立并严格执行贷款面谈制度
- 贷款资金须采用受托支付，确保支付给符合合同约定用途的交易对象
- 消费贷款最高额度、期限由监管部门规定

## 4. 项目融资业务指引

- 项目融资指以项目的未来收益和资产为还款来源的融资方式
- 银行应要求将项目资产和项目收益权为贷款设定担保
- 贷款期限应与项目投资回收期匹配

# 二、银行核心业务指标

## 对公业务指标体系

| 指标 | 说明 |
|---|---|
| 存款余额 | 企业活期/定期/通知存款合计 |
| 贷款余额 | 流动资金贷款、固定资产贷款、票据贴现等 |
| 中间业务收入 | 结算手续费、保函费、承兑费、咨询费等 |
| 不良率 | 不良贷款余额 / 贷款总额 ≤ 2% |
| 拨备覆盖率 | 贷款损失准备 / 不良贷款余额 ≥ 150% |
| 净息差（NIM） | 利息净收入 / 生息资产平均余额 |
| 存贷比 | 贷款余额 / 存款余额 |

## 对公客户经理考核指标

- 存款日均余额（权重最高）
- 贷款余额及利息收入
- 中间业务收入（保函、承兑、代发工资等）
- 客户新增数及客户流失率
- 不良贷款率（风险控制）
- 交叉销售率（客户持有产品数）

# 三、企业财务分析要点（对公尽职调查）

## 资产负债表核心指标

| 指标 | 公式 | 健康范围 |
|---|---|---|
| 资产负债率 | 总负债 / 总资产 | 制造业 < 60%，贸易 < 70% |
| 流动比率 | 流动资产 / 流动负债 | > 1.5 |
| 速动比率 | (流动资产 - 存货) / 流动负债 | > 1.0 |
| 应收账款周转率 | 营业收入 / 应收账款平均余额 | 与行业对比 |
| 存货周转率 | 营业成本 / 存货平均余额 | 与行业对比 |

## 利润表核心指标

| 指标 | 公式 | 说明 |
|---|---|---|
| 毛利率 | (营业收入 - 营业成本) / 营业收入 | 反映产品竞争力 |
| 净利率 | 净利润 / 营业收入 | 反映综合盈利能力 |
| 营收增长率 | (本期营收 - 上期营收) / 上期营收 | 反映成长性 |

## 现金流量表关注点

- **经营活动现金流净额**：必须为正，且能够覆盖利息支出
- **投资活动现金流**：大幅为负表示企业在扩张投资
- **筹资活动现金流**：反映企业融资能力

# 四、银行业热点话题

## 1. 数字化转型
- 手机银行用户数、MAU（月活用户）
- 线上贷款产品（如兴闪贷）占比
- 人工智能在风控、客服中的应用

## 2. 绿色金融
- 绿色信贷余额及占比
- 碳减排支持工具
- ESG（环境、社会、治理）评级

## 3. 普惠金融
- 小微企业贷款余额及利率
- "两增两控"目标（小微企业贷款增速不低于各项贷款、户数不低于上年；控制不良率和综合成本）
- 涉农贷款

## 4. 利率市场化
- LPR 改革对企业融资成本的影响
- 存款利率自律机制
- 净息差收窄的应对策略

# 五、常见金融术语

| 术语 | 释义 |
|---|---|
| LPR | 贷款市场报价利率，银行贷款定价基准 |
| MLF | 中期借贷便利，央行向商业银行提供中期资金的货币政策工具 |
| SLF | 常备借贷便利，央行向商业银行提供短期流动性支持 |

# 六、面试常见金融场景题

## 场景1：贷款审批
Q: 审查一家化工企业5000万流动资金贷款申请，你需要关注哪些风险点？
A: 1）行业风险：化工行业周期性、环保政策影响；2）经营风险：产能利用率、上下游议价能力；3）财务风险：负债率、现金流、应收账款质量；4）担保风险：抵押物是否足值、变现能力；5）合规风险：是否在限制行业名录。

## 场景2：贷后管理
Q: 如何发现企业贷款出现风险预警信号？
A: 1）账户流水异常：回款减少、资金归行率下降；2）征信变化：他行贷款逾期、新增担保；3）经营变化：核心人员离职、主营业务变更；4）外部信息：被列入失信名单、涉及诉讼；5）贷后检查：现场走访发现异常。

## 场景3：客户营销
Q: 如何向一家新成立的科技公司营销银行产品？
A: 1）先开户，建立基础结算关系；2）了解企业资金需求和痛点；3）推荐组合产品：代发工资+企业网银+流动资金贷款；4）做好服务，增强粘性；5）逐步拓展到理财、供应链金融等增值业务。
